# Lively Wallpaper Host

Static GitHub Pages host for three personal Lively Wallpaper videos.

## Expected video files

Upload these exact files into the `videos/` folder:

- `videos/sasuke.mp4`
- `videos/kali.mp4`
- `videos/vegeta.mp4`

The HTML pages are already configured to autoplay, mute, loop, fill the screen, and work as Lively web wallpapers.

## GitHub Pages

Publish from:

- Branch: `main`
- Folder: `/ (root)`

After Pages is enabled, use:

- `https://socgabrielcardoso.github.io/wallpapertest/sasuke/`
- `https://socgabrielcardoso.github.io/wallpapertest/kali/`
- `https://socgabrielcardoso.github.io/wallpapertest/vegeta/`

## Lively

In Lively Wallpaper:

1. Add Wallpaper
2. Enter URL
3. Paste one of the URLs above
4. Confirm
